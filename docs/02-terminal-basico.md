# Terminal básico

O terminal executa comandos no computador. Antes de pressionar Enter, leia o comando e saiba em qual pasta você está.

| Comando | Para que serve |
|---|---|
| `pwd` | mostra a pasta atual |
| `ls` | lista arquivos e pastas |
| `cd nome-da-pasta` | entra em uma pasta |
| `cd ..` | volta uma pasta |
| `mkdir nome` | cria uma pasta |
| `code .` | abre a pasta atual no VS Code |
| `clear` | limpa a tela, não os arquivos |

Pratique: localize o repositório com `pwd`, liste seu conteúdo com `ls` e abra-o com `code .`. Use Tab para completar nomes e seta para cima para recuperar comandos.

Evite executar comandos copiados sem entender. Em especial, pare e peça ajuda diante de comandos de remoção (`rm`) ou executados como administrador (`sudo`).
