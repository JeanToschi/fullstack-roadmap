# Como receber code review

Code review avalia a mudança e compartilha conhecimento; não é uma avaliação pessoal.

Para cada comentário: entenda o comportamento apontado; localize o trecho; pergunte se a intenção não estiver clara; faça a menor correção adequada; teste novamente; responda com o que mudou e envie o commit.

Exemplo: `Entendi que devemos retornar 404. Você sugere tratar isso no controller ou no service? Minha leitura é que a regra pertence ao service porque...`

Não responda apenas “feito” quando uma explicação ajudar. Não aceite uma sugestão automaticamente: entenda o impacto e saiba explicar a versão final.
