# Como pedir ajuda

Uma boa pergunta informa: o que estou tentando fazer; o que esperava; o que aconteceu; qual erro apareceu; o que já tentei; qual parte não entendi.

Pergunta ruim: `Não funciona.`

Pergunta útil:

> Estou tentando buscar um produto por ID. Esperava receber o produto 1, mas recebo `undefined`. Conferi o array e o produto existe. Também imprimi o ID e ele chega como texto. Não entendi se estou usando `find` ou comparando os tipos corretamente.

Antes de pedir ajuda, reproduza o erro, leia arquivo e linha indicados, formule uma hipótese e teste uma mudança por vez. Compartilhe texto e código, nunca senhas ou tokens.
