# Como abrir um Pull Request

Antes do PR, confirme que a branch foi enviada com `git push`, abra a página do repositório e escolha comparar sua branch com `main`.

Preencha o template com o problema, a alteração, passos reproduzíveis para testar, vínculo com a Issue e decisões relevantes.

Revise a aba **Files changed** como se o código fosse de outra pessoa. Remova logs temporários e arquivos sem relação. Mantenha o PR pequeno e não faça merge antes do review.

Depois de corrigir um comentário, faça novo commit e push na mesma branch: o PR será atualizado automaticamente.
